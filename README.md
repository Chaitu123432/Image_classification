# Image Classification Using CIFAR-100

This repository contains a project demonstrating the performance of various deep learning models on the CIFAR-100 dataset.

## Models Evaluated:
- ResNet50
- InceptionV3
- VGG16

## How to Run:
1. Install dependencies: `pip install -r requirements.txt`
2. Open the notebook: `jupyter notebook notebooks/Image_Classification_CIFAR100_Updated.ipynb`
3. Run all cells sequentially.

## Results:
The results include accuracies achieved by the models, along with visualizations of predictions and insights.
